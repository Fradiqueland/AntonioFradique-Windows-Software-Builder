# Arquivo de versões anteriores

Os ZIPs nesta pasta são versões históricas do antigo Windows Software Builder. Os instaladores atuais do **Windows & Mac Software Builder v2.5** estão na Release indicada no README principal.

Para instalar a versão atual, use os [downloads Windows e Mac no README principal](../README.md#descarregar-e-instalar-o-builder). Para criar os instaladores a partir do código, siga [BUILD-V2.md](../Windows-Mac-Software-Builder/BUILD-V2.md).
