# v2.6.3 — Exportar módulos Mac a partir do Windows

Corrige o bloqueio «Executável Mac sem permissão de execução» ao exportar um
projeto que inclui um módulo **Software portable** com uma aplicação Mac válida.
O Windows não conserva os bits Unix de execução; a v2.6.2 tratava essa ausência
como um executável Mac inválido e impedia a exportação.

Ao criar o ZIP ou um arquivo de projeto `.wsmb` no Windows, os executáveis
Mach-O validados dos módulos portable recebem a permissão **0755** no arquivo.
A origem, os ficheiros do projeto, os bytes dos executáveis e o modelo assinado
do Viewer não são alterados. Os recursos normais não recebem permissão de
execução. Os controlos nativos de permissões Unix permanecem em Mac/Linux.

A correção revalida os ficheiros, incluindo projetos guardados na v2.6.2 com
metadados antigos. **Não é necessário voltar a importar o módulo nem recriar o
projeto num Mac**: atualizar o construtor e voltar a exportar para Mac.

Continua a ser necessário um executável Mac válido no módulo. Uma aplicação
Windows não se transforma numa aplicação Mac através desta correção; a opção
Wine mantém o seu funcionamento e requisitos existentes.

## Validação

- O teste de regressão falha no código publicado na v2.6.2 com a mensagem exata
  enviada pelo utilizador e passa com a correção.
- 251 testes locais aprovados; um teste opcional de PHP ignorado.
- ZIP Mac e `.wsmb` conservam bytes e configuração, executáveis principais e
  auxiliares recebem 0755 apenas no Windows, recursos e bibliotecas não recebem
  execução, e os modos dos ficheiros locais permanecem intactos.
- A validação nativa Windows testa um Mach-O real extraído do modelo Mac
  verificado, a exportação completa e o SHA-256 do executável, tanto com o
  código-fonte como com o código do instalador.
- Sentido inverso verificado: um executável Windows sem bits Unix de execução
  é aceite e exportado corretamente. O teste passa também no código da v2.6.2.
  O teste nativo Mac repete a exportação com um PE real do modelo Windows.
- Os novos instaladores só são publicados após os testes nativos completos.
