# Windows & Mac Software Builder v2.5

Versão técnica: **2.5.0**. O Builder é o editor; os produtos exportados são aplicações independentes para Windows e Mac.

## Tamanho e qualidade

- Compressão máxima sem perdas dos instaladores, templates e ZIPs exportados.
- O Builder guarda uma única cópia dos dois arquivos de fontes FFmpeg/x264 idênticos, em vez de os repetir nos modelos Windows e Mac. Na exportação de um projeto com IPTV, repõe os arquivos completos e verifica os SHA-256 fixados. Arquivos ausentes ou corrompidos impedem a exportação sem substituir um ficheiro anterior. Os templates autónomos publicados pela etapa Viewer continuam completos.
- Ferramentas de conversão de ícones e edição de EXE são excluídas do Viewer porque só são utilizadas pelo Builder. O Builder mantém as ferramentas necessárias à plataforma.
- Os projetos sem IPTV omitem FFmpeg e ffprobe. Um projeto com IPTV mantém os binários, fontes correspondentes, licenças e receita de compilação completos.
- PHP é incluído num projeto exportado apenas quando um módulo HTML/PHP realmente necessita dele. Importar HTML não exige PHP.
- No Mac, os runtimes opcionais passam a estar na pasta `.data`, ao lado da `.app`. Isto permite omitir o que não é usado sem alterar os bytes da aplicação assinada. Templates antigos são suportados; não é retirado conteúdo de bundles antigos assinados.
- Vídeo, áudio, imagens, conteúdos, idiomas e arquiteturas Mac não são reduzidos nem reconvertidos automaticamente. Existe um tamanho mínimo imposto pelos motores Electron Windows e Mac incluídos para exportação autónoma.

Mantenha a aplicação Mac e a sua pasta `.data` juntas. Se a aplicação pedir a localização dessa pasta, selecione a pasta completa; os runtimes incluídos também serão procurados nela. O instalador do Builder mantém FFmpeg para pré-visualizar todos os projetos IPTV.

## Android / APK: estado nesta versão

O cartão **Android / APK — Experimental** apresenta informação apenas quando é escolhido. **Não importa nem executa APK nesta versão.** Não foi incorporado um motor Android validado e não existe uma aplicação APK autónoma exportável.

O painel explica o objetivo de incluir tudo no Builder e apenas nos produtos que utilizem APK, o aumento de tamanho e memória, os requisitos de virtualização e as limitações de compatibilidade. Não instala ferramentas, não descarrega imagens Android e não procura emuladores no sistema. Um projeto manipulado com um tipo APK é rejeitado antes de criar uma exportação; o Viewer apresenta um aviso em vez de tentar executar um ficheiro.

A execução funcional depende dos critérios descritos em [ANDROID-APK.md](ANDROID-APK.md). Não será apresentada como pronta antes de ser demonstrada no Builder e num produto exportado, em Windows x64, Mac Intel e Mac Apple Silicon, sem instalações externas. iOS/IPA não é suportado.

## Atualização e validação

Instale os novos pacotes e volte a exportar os projetos para aplicar as otimizações; os produtos anteriormente distribuídos não são alterados automaticamente. A compilação nativa verifica fontes/licenças, transcodificação IPTV, exportações com e sem runtimes, permissões e assinatura Mac.

`node scripts/report-package-size.js` grava as medidas reais da compilação em `dist/package-size-report.json`. Os logs do teste Electron indicam o tamanho do mesmo projeto HTML com e sem IPTV. O tamanho do instalador não é o mesmo que o ZIP de artefacto do GitHub; compare medidas equivalentes.
