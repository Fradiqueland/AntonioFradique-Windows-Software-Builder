# v2.6.2 — Banners com fecho opcional e GIF animado

Em **Aparência → Banners**, cada banner (topo e rodapé) dispõe da opção
**Permitir fechar com X**. A opção está desligada por predefinição, incluindo
nos projetos antigos. As duas permissões são independentes e ficam guardadas
no projeto e nas exportações Windows e Mac.

Quando permitido, o X fecha apenas esse banner e liberta o respetivo espaço
para o conteúdo aberto, sem abrir o link de destino ou reiniciar o módulo.
O botão funciona com rato e teclado e tem uma descrição no idioma escolhido.
O banner reaparece quando o utilizador volta a abrir a aplicação. Não é
alterada a configuração original do projeto.

O construtor indica **728 × 90 px** junto das duas imagens e identifica o
suporte para **PNG, JPG e GIF, incluindo animações**. As imagens são copiadas
sem conversão; a animação GIF mantém os bytes originais. Imagens maiores
continuam a ajustar-se ao espaço disponível, com altura máxima de 90 px.
O botão X ocupa uma zona separada da imagem.

## Utilização

1. Abrir **Aparência → Banners** e escolher uma imagem para o topo ou rodapé.
2. Ativar **Permitir fechar com X** nos banners que o utilizador pode ocultar.
3. Pré-visualizar e exportar para Windows ou Mac.

É necessário voltar a exportar produtos antigos com esta versão para incluir
o novo comportamento do Viewer. A opção de fecho refere-se aos banners de
imagem configurados no projeto; as faixas promocionais de texto mantêm o
comportamento existente.
