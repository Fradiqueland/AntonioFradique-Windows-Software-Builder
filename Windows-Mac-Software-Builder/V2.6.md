# v2.6 — projetos editáveis e gravação mais fiável

## Importar e exportar projetos

Em **Projetos**, cada linha tem **Exportar projeto**. Escolha onde guardar o ficheiro `.wsmb`. Para o recuperar neste computador ou noutro, use **Importar projeto** no mesmo separador.

O arquivo inclui as definições, módulos, imagens, ícone e ficheiros importados, incluindo pastas HTML/PHP e software portable. Não inclui o motor Electron nem os runtimes FFmpeg/PHP; o Builder instalado fornece esses componentes ao criar a aplicação final. Os recursos externos continuam a depender das respetivas ligações e serviços.

A importação cria um projeto independente, sem substituir os existentes. As aplicações portable importadas recebem uma nova revisão para não partilharem os dados de execução da cópia original. As permissões e ligações internas são preservadas no Mac; no Windows, as ligações internas são materializadas para dispensar privilégios de administrador.

Guarde os módulos antes de exportar: o arquivo contém o conteúdo já gravado. As alterações pendentes nos formulários de aparência são gravadas antes da transferência. O arquivo pode conter conteúdos privados, palavras-passe do projeto e ligações configuradas; não é cifrado.

**Criar aplicação**, no cabeçalho, continua a levar à exportação do produto Windows/Mac para os destinatários. Esses EXE/ZIP de distribuição e os instaladores do Builder não são arquivos de projeto `.wsmb`.

## Correções

- Alterações de aparência dentro do intervalo de gravação automática já não são descartadas ao abrir, criar, duplicar, renomear ou apagar um projeto. A pré-visualização e a criação da aplicação também aguardam a gravação.
- Gravações falhadas mantêm as alterações no formulário e impedem a mudança de projeto até serem resolvidas.
- A gravação do ícone participa no bloqueio de alterações concorrentes.
- Se um módulo falhar ao guardar, os novos ficheiros copiados são removidos e a configuração anterior permanece intacta. Uma imagem de galeria inexistente deixa de ser ignorada silenciosamente. IDs de módulos repetidos são rejeitados.
- Os formulários de gravação automática não usam submissão nativa e não podem navegar para outra página. Se o processo do editor terminar inesperadamente, uma janela permite reabri-lo sem reiniciar toda a aplicação.

O ecrã branco relatado ao alternar os banners não foi reproduzido nos testes locais. As proteções acima não constituem confirmação de que a causa específica no computador original foi identificada. O teste Chromium usa o renderer completo, alterna ambos os banners, simula uma falha de gravação e verifica que o documento principal continua aberto.

## Validação

Os testes incluem transferência com comparação dos bytes dos recursos, referências inválidas, ficheiros corrompidos, caminhos fora do projeto, ligações cíclicas, falha do índice de projetos e gravações interrompidas. O workflow exige ainda os testes em Electron nativo Windows/Mac, com código fonte e empacotado, antes de publicar os instaladores. O teste de arquivo nativo transfere um ASAR real e volta a executar o programa portable importado.

Mantêm-se a exportação offline, as verificações IPTV/FFmpeg e os limites da [v2.5](V2.5.md). A importação e execução APK continuam indisponíveis.
